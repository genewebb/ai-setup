# Complexity Analysis

Assess code complexity and maintainability:

## Cyclomatic Complexity

- Functions with high complexity (>10) flagged
- Nested conditionals and loops identified
- Suggest extraction of complex logic into smaller functions

## File Size

- Files exceeding 500 lines flagged for potential splitting
- Large components suggest breaking into smaller components

## Dependency Complexity

- Deep dependency chains identified
- Circular dependencies detected
- Unnecessary dependencies flagged

## Cognitive Complexity

- Complex nested logic patterns
- Multiple responsibilities in single functions/components
- Hard-to-follow code paths
