- Readiness: poll `GetAttributesAsync` until all expected attrs present (gateway metadata lag) — or for direct-SQL collector tests, poll `SELECT TOP(0)` of the needed columns against `data.[t{name}]`.
- `[DoNotParallelize]` the class (model mutation). Provision entity/attribute **definitions once per class** (`[ClassCleanup]` + static guard) — only RECORDS must be per-test (unique codes). `DeleteEntityAsync` in cleanup cascades records.
- Match-enabled column needs (`[Golden Record]`/`[Match Cluster]`/`[Match Status]`) are satisfied by plain attributes with those exact names (user-approved; no real matching strategy).
- Source pool `RecordPoolRepository` reads `ModelSource.dbo.RetailClient` (200M test-DATA table — legit infra, leave as-is). Column→attribute remaps: `PhoneNumber`→`"Phone Number"`, `SourceSystem`→`"Source System"`; the other 29 RecordColumns pass through.
