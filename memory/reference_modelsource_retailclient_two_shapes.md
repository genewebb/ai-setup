**Production `ModelSource.dbo.RetailClient`** (SMVMDB2 / CORPSQL03, 500M rows, 100M per source system
Apple/Credibly/Intuit/Seed/Walmart, generated by TestData.Mutation) has **31 columns**: no `ClientId`,
`MailingAddressLine2`, `OriginalRecordId2`; has `Ssn`, `Gender`; `DateOfBirth` is SQL `date`.
It will not be changed — code adapts.

**Sibling tables** `RetailClient1M/15M/300M` and the local CORPLTR94 `RetailClient` (copy of 15M) have the
**35-column** shape (adds `ClientId`, `MailingAddressLine2`, `OriginalRecordId2`, `OriginalSourceName`,
`EnrichmentBatchNumber`, `NewCode`); `DateOfBirth` there is `nvarchar(15)` text `yyyy-MM-dd`.
`SourceSystem.TargetTable` picks the table, so one code path hits both.

**2026-09-15 fix**: `RecordPoolRepository` resolves the column list once per table from
`[Db].INFORMATION_SCHEMA.COLUMNS`, intersects with `MatchingConstants.RetailClientSourceColumns` (the single
list; `RecordColumns` aliases it), logs missing columns once at Information / `RECORD_MIX`, and normalises
`DateOfBirth` to `yyyy-MM-dd` text. Tests: `Testing.SpeedMerchants.Unit/Tests/Matching/RecordPoolColumnShapeTests.cs`.
Failure signature it fixes: `Invalid column name 'ClientId'` on every source system, zero records,
"No records returned from GetNextBatchAsync at iteration 1", WorkloadExecution Failed.

**Open gap**: `MatchFieldMap` whitelist still uses the full list, so an eligibility predicate on `ClientId`
would still fail against the production table.

**Build gotcha**: `speed-merchants.sln` lists `TestData.CloneAndMutate.csproj` and `TestData.Shared.csproj`
that are not on disk, so `dotnet build speed-merchants.sln` dies at restore. Build per project.

**How to apply:** never hard-code a RetailClient column list again; read `RetailClientSourceColumns`. When a
matching run returns zero records on iteration 1, check for `Invalid column name` in the Seq log before
suspecting the data. The [[testauto-matching-source-data]] skill's SS 1/2/3 + 20/30/40 story predates the
Apple/Credibly/Intuit/Seed/Walmart production dataset.
