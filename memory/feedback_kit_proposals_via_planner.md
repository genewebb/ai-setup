**Why:** the planner knows the kit inbox contract and Send-InboxItem.ps1. Spelling out filing steps in the prompt duplicates its own rules.

**How to apply:** for stream-kit changes, write a proposal document with numbered items, an order, and "done when" checks, staged in `\\SMVMTR1\d$\Laptop\<name>\`. Hand Gene a short prompt: read this, file it with the kit inbox in the stated order. Don't script the filing itself.
